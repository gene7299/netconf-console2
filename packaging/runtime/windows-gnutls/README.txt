Windows GnuTLS runtime

These DLLs are from the MSYS2 UCRT64 packages used to provide RFC 8071
TLS Call Home heartbeat support in the Windows CLI and Qt GUI bundles.

Source repository: https://repo.msys2.org/mingw/ucrt64/
GnuTLS package: mingw-w64-ucrt-x86_64-gnutls 3.8.13-3
Toolchain/runtime packages: MSYS2 UCRT64 GCC 16.2.0-4 and the package
dependencies recorded in the corresponding MSYS2 package metadata.

GnuTLS and its bundled dependencies remain under their original licenses.
See https://www.gnutls.org/ and https://www.msys2.org/ for the upstream
project and redistribution information.
